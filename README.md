# Nikhil Web Studio — 3-Day Website

## Before publishing
Open `index.html` and replace every `91XXXXXXXXXX` with your WhatsApp number in international format.
Example: 919876543210

Also replace:
- `Nikhil Web Studio` with your final brand name if desired.
- `https://YOUR-DOMAIN.example/` with your real domain/subdomain.

## Free hosting
### GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `robots.txt`, and `sitemap.xml`.
3. Repository Settings → Pages.
4. Deploy from the `main` branch / root.
5. GitHub gives you a free `username.github.io` address.

### Netlify
Drag the project folder into Netlify's deploy area, or connect the GitHub repository.

### Cloudflare Pages
Create a Pages project and connect the GitHub repository.

## Contact form
The form intentionally uses WhatsApp instead of a paid backend. This means the website works on free static hosting without a server.

## SEO
The page includes:
- title and meta description
- Open Graph metadata
- canonical URL placeholder
- robots.txt
- sitemap.xml
- basic Schema.org structured data

After publishing, submit the final URL in Google Search Console.
